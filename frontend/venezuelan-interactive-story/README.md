# Venezuelan Interactive Story

## Descripción del Proyecto
Este proyecto es una historia interactiva para niños que explora la cultura, geografía y tradiciones de Venezuela. Utilizando React y CoreUI, la aplicación proporciona una experiencia educativa y entretenida, permitiendo a los niños aprender sobre Venezuela de manera divertida e interactiva.

## Estructura del Proyecto
El proyecto está organizado en varias carpetas y archivos que facilitan la navegación y el mantenimiento. A continuación se describe la estructura principal:

- **src/**: Contiene el código fuente de la aplicación.
  - **_nav.js**: Configuración de navegación general.
  - **_nav_student.js**: Navegación específica para estudiantes.
  - **_nav_teacher.js**: Navegación específica para profesores.
  - **App.js**: Punto de entrada de la aplicación.
  - **index.js**: Renderiza el componente principal en el DOM.
  - **routes.js**: Define las rutas de la aplicación.
  - **store.js**: Configura el estado global utilizando Redux.
  - **assets/**: Contiene los activos de la aplicación, como logos e imágenes.
  - **components/**: Componentes reutilizables de la interfaz de usuario.
  - **config/**: Configuraciones relacionadas con la autenticación.
  - **layout/**: Define la estructura general del layout de la aplicación.
  - **scss/**: Archivos SCSS para estilos globales y específicos.
  - **views/**: Contiene las diferentes vistas de la aplicación.

## Instalación
Para instalar las dependencias del proyecto, ejecuta el siguiente comando en la raíz del proyecto:

```
npm install
```

## Ejecución
Para iniciar la aplicación en modo de desarrollo, utiliza el siguiente comando:

```
npm start
```

La aplicación se abrirá en `http://localhost:3000`.
